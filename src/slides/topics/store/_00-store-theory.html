The Store

What a Store actually is?

A store is a shared state tree plus a notification contract: one source of truth for the data, and a predictable way to tell the rest of the app when that data changes.
The store is not the renderer and it is not the business logic: it is the stable place where both meet the current state.

Proxy watches, Reflect does the work

    
class Store {
  constructor(initialState) {
    this.target = deepClone(initialState);
    this.state = this.#createProxy(this.target, []);
  }

  #createProxy(target, path) {
    if (!isObject(target)) return target;
    if (this.proxyCache.has(target)) return this.proxyCache.get(target);

    const proxy = new Proxy(target, {
      get: (raw, key) => {
        const value = Reflect.get(raw, key);
        return isObject(value) ? this.#createProxy(value, [...path, key]) : value;
      },
      set: (raw, key, value) => {
        const old = raw[key];
        const result = Reflect.set(raw, key, value);
        if (old !== prepared) this.#emitChange([...path, key], old, value);
        return result;
      },
    });

    return proxy;
  }
}
