Lifecycle Callbacks

  1. constructor(): element created, state only, prefer no DOM or attributes
  2. connectedCallback(): inserted into the DOM, render and attach listeners here
  3. attributeChangedCallback(): an observed attribute changes, update the element accordingly
  4. disconnectedCallback(): removed from the DOM, clean up listeners, timers, observers
Understanding the lifecycle is crucial for proper resource management and avoiding memory leaks.

All four lifecycle callbacks in a class

      
class PixButton extends HTMLButtonElement {
  constructor() {
    super();
    // initialize state only, no DOM here
    this.count = 0;
  }

  connectedCallback() {
    // DOM and attributes are ready: render + attach listeners
    this.render();
    this.addEventListener('click', this.handleClick);
  }

  disconnectedCallback() {
    // remove listeners and clear timers/observers
    this.removeEventListener('click', this.handleClick);
    this.interval && clearInterval(this.interval);
  }

  static get observedAttributes() {
    return ['value', 'disabled'];
  }

  attributeChangedCallback(name, oldValue, newValue) {
    name === 'value' && this.updateValue(newValue);
  }
}
