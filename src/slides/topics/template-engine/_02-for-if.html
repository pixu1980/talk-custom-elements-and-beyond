<for> and <if> blocks

Each block keeps its own DOM part, so the engine updates the existing nodes in place: focus, caret and form state survive the re-render. Inner markup uses {{ }}, and there is no second syntax. 
    
<!-- one block per item, keyed by id -->
<for each="todo in todos">
  <li><ceb-todo-item data-id="{{ todo.id }}"></ceb-todo-item></li>
</for>

<!-- conditional block -->
<if condition="isEmpty">
  <p>Nothing matches the current filters yet.</p>
</if>
The engine parses <for> and <if> regions and reconciles them as DOM parts, keyed by item id.
