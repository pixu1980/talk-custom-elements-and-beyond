Attributes vs Properties

Aspect Attributes (HTML) Properties (JS)
Type strings (or null) any JavaScript value
Defined in HTML markup JavaScript
Access getAttribute() / setAttribute() element.prop
Reactivity triggers attributeChangedCallback() does not trigger callbacks

Reflection & observed attributes

      
class MyButton extends HTMLButtonElement {
  // reflection: keep property and attribute in sync
  get value() {
    return this.getAttribute('value');
  }

  set value(val) {
    this.setAttribute('value', val);
  }

  // reactivity: observe only the attributes you need
  static get observedAttributes() {
    return ['value', 'disabled'];
  }

  attributeChangedCallback(name, oldValue, newValue) {
    name === 'value' && this.updateValue(newValue);
  }
}

Reflection & observed attributes

  • Use attributes for simple, serializable values
  • Use properties for complex objects or functions
  • Reflect simple properties to attributes when possible
